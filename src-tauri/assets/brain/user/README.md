This folder is for User Customizations for Dropel Brain.

- `custom_genres.json`: Add your own genre profiles here to extend the core knowledge base.
- `overrides.json`: Override specific mixing rules or theory (coming soon).

Example `custom_genres.json`:
```json
[
  {
    "name": "My Custom Trap",
    "bpm_range": [140, 160],
    "key_tendencies": ["Cm", "Fm"],
    "instrumentation": ["808", "HiHats"],
    "spectral_targets": {},
    "mixing_tips": ["Boost 60Hz"]
  }
]
```
